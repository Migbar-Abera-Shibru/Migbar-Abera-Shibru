## 🧠 What I Build

I design and ship **AI-powered backend systems** across three core areas:

- **Retrieval-Augmented Generation (RAG):** End-to-end pipelines that ingest documents,  
  embed them into vector stores (Pinecone), and serve accurate, context-grounded answers  
  through LLM APIs — including Azure OpenAI and Groq.

- **Agentic AI Systems:** Multi-step, decision-making agents using LangGraph and LangChain  
  that interact with databases, APIs, and external tools — not just chat, but act.

- **Intelligent APIs and Backends:** FastAPI services and Node.js backends that wrap  
  AI capabilities into clean, deployable, containerized products using Docker.

The problems I focus on: unstructured knowledge retrieval, automated code quality,  
financial decision support, and making AI accessible through real products.
